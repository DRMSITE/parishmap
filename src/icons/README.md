# Icons

Solid icons from [Font Awesome Free](https://fontawesome.com/license/free) 7.3.0, licensed
CC BY 4.0 (the icons), SIL OFL 1.1 (fonts) and MIT (code). Each file keeps Font Awesome's own
licence comment, which satisfies the attribution requirement. Copyright Fonticons, Inc.

`src/web-awesome.js` registers them as Web Awesome's default icon library, so no icon is
fetched from a third party at run time. To add one, copy it from `svgs/solid` in the
`@fortawesome/fontawesome-free` package.
